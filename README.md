# k15k-linux-kernel (experimental)
Rebuild of the Tecno K15K (Spark 10C, Unisoc) android12-5.4.254 GKI kernel with
PID_NS, IPC_NS, USER_NS, SYSVIPC and POSIX_MQUEUE enabled, for Halium/Linux research.
NOT a KernelSU build. For KernelSU + SUSFS on Unisoc see: gki-susfs-build2
Status: untested. Not yet booted on a device.
